- **FSL alphabet data** by John Gabriel Porton. Kaggle lists version 1 as CC0. The repository tracks the resulting model and evaluation reports. [Dataset](https://www.kaggle.com/datasets/japorton/fsl-dataset) · [Dataset metadata](https://www.kaggle.com/api/v1/datasets/view/japorton/fsl-dataset)
- **FSL-105 v2** by Isaiah Jassen Tupal, licensed CC BY 4.0. A-B Sign! uses this dataset for number training and lesson demonstrations. The clips were resized, muted, and re-encoded to WebM. [FSL-105](https://data.mendeley.com/datasets/48y2y99mb9/2) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) · [Original clip paths](../src/renderer/vocabulary.json)
- **Transactional Filipino Sign Language Dataset v2** by Franz Columna and Angela Cardano, licensed CC BY 4.0. A-B Sign! aligns and resamples these landmark recordings for number training. [Transactional FSL](https://data.mendeley.com/datasets/jdyrr7cm4z/2) · [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)
- **MediaPipe** by Google. The `.task` bundles combine Google’s hand and gesture components with classifiers trained for this project. [MediaPipe license](https://github.com/google-ai-edge/mediapipe/blob/master/LICENSE) · [Gesture Recognizer model information](https://developers.google.com/edge/mediapipe/solutions/vision/gesture_recognizer#models)
